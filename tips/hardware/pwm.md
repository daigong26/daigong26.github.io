# PWM：不只是调光，是激光功率与电机速度的底层语言

## 现场问题

激光器标称 3000W，怎么实现 1500W 输出？伺服电机怎么从 0 加速到 3000rpm 而不冲击机械结构？

## PWM 本质

**脉冲宽度调制** = 快速开关 + 占空比控制
高电平时间
───────────  = 占空比（Duty Cycle）
总周期时间

- 占空比 50%：一半时间通电，等效功率 50%
- 占空比 100%：全功率输出
- 频率够高（>20kHz，人耳听不到）时，电机/激光器感受到的是"平均功率"

## 激光切割中的应用

| 场景 | PWM 作用 | 关键参数 |
|------|---------|---------|
| 激光功率调节 | 控制占空比实现 10%-100% 功率输出 | 频率 5-50kHz，占空比 0-100% |
| 脉冲穿孔 | 高占空比脉冲 + 低占空比冷却交替 | 脉冲频率、占空比、波形 |
| 伺服电机调速 | 驱动器接收 PWM 信号，控制电机转速 | 脉冲频率对应转速，脉冲数对应位移 |

## 现场感悟

- **PWM 频率选错**：切割薄板时 PWM 频率太低，功率波动导致切缝边缘锯齿
- **死区时间**：H 桥驱动上下管切换时必须留死区，否则直通炸管
- **与模拟量的区别**：PWM 是"数字手段实现模拟效果"，抗干扰比纯模拟量好，但 EMI（电磁干扰）更强，布线要远离信号线

## 与 Arduino 试验台的关联

Arduino `analogWrite()` 本质就是 PWM（默认 490Hz 或 980Hz）。要控制激光器功率或电机速度，必须理解这个频率是否匹配被控对象的响应速度。
