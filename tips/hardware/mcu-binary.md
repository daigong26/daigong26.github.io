# 单片机与二进制：代码如何变成引脚上的高低电平

## 核心问题

`digitalWrite(13, HIGH)` 在 Arduino 里是一行代码，物理上发生了什么？

## 从代码到电平的链路
C 代码 → 编译器 → 汇编指令 → 机器码（二进制） → 烧录到 Flash
↓
CPU 取指令 → 解码 → 操作寄存器
↓
寄存器某一位 = 1 → 驱动电路 → 引脚输出 5V（HIGH）
寄存器某一位 = 0 → 驱动电路 → 引脚输出 0V（LOW）

## 二进制与硬件的映射

以 Arduino Uno（ATmega328P）为例：

- **PORTB 寄存器**：8 位，控制数字引脚 8-13
- 写 `PORTB = 0b00100000`（二进制）= `0x20`（十六进制）
- 第 5 位（从 0 开始数）= 1 → 引脚 13 输出 HIGH
- 其余位 = 0 → 引脚 8-12 输出 LOW

```c
// 这两行在物理上是等价的
digitalWrite(13, HIGH);
PORTB |= (1 << 5);  // 直接操作寄存器，更快
