# 磁电世界：编码器、电磁阀与霍尔传感

## 现场问题

伺服电机怎么知道转了 1 圈还是 1.5 圈？切割头怎么知道移动了 100mm 而不是 99.8mm？

## 核心器件

| 器件 | 原理 | 应用 |
|------|------|------|
| **光电编码器** | 光栅盘 + 光电传感器，转一圈输出固定脉冲数 | 伺服电机位置反馈 |
| **磁电编码器** | 磁栅 + 霍尔元件，抗油污比光电强 | 恶劣环境（切割车间粉尘多） |
| **霍尔传感器** | 磁场变化 → 电压变化 | 气缸位置检测（磁性开关）、无接触限位 |
| **电磁阀** | 线圈通电 → 磁场 → 阀芯移动 → 气路切换 | 辅助气体开关、夹具控制 |

## 编码器分辨率

- 2500 线编码器：转一圈输出 2500 个脉冲
- 经过 4 倍频（AB 相正交解码）：实际分辨率 = 10000 脉冲/圈
- 配合 5mm 导程丝杠：1 脉冲 = 5mm / 10000 = 0.0005mm = 0.5μm

## 现场感悟

- **编码器脏了**：光电编码器在切割车间用半年，光栅盘积灰，丢脉冲导致定位漂移，必须定期吹气清洁
- **磁电编码器更适合车间**：粉尘、油雾环境下，磁电比光电可靠，但精度略低
- **电磁阀响应时间**：从通电到气路切换约 20-50ms，高速切割时换气体（氧气→氮气）必须提前预留这个时间
- **霍尔开关距离**：磁性开关感应距离 2-5mm，气缸活塞上磁环位置装偏 1mm 就检测不到

## 与激光切割的关联

- 切割头 Z 轴定位：编码器反馈 → 闭环控制 → 跟随精度 ±0.1mm
- 辅助气体切换：电磁阀 + 霍尔检测 → 确认气路到位后才允许起刀
- 板材检测：霍尔传感器检测夹具是否夹紧 → 未夹紧禁止启动
