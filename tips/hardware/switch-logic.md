# 开关量与真值表：按钮、限位、继电器的状态逻辑

## 现场问题

激光切割设备上有：急停按钮、启动按钮、限位开关、光电传感器、门磁开关。PLC 程序怎么知道"现在能不能启动切割"？

## 开关量类型

| 类型 | 常态 | 触发时 | 典型应用 |
|------|------|--------|---------|
| **常开（NO）** | 断开 | 闭合 | 启动按钮、行程开关 |
| **常闭（NC）** | 闭合 | 断开 | 急停按钮、安全门、限位保护 |
| **PNP** | 高电平有效 | 输出 24V | 欧系 PLC 常用 |
| **NPN** | 低电平有效 | 输出 0V | 日系 PLC 常用 |

## 启动条件真值表

| 条件 | 状态 | 允许启动？ |
|------|------|-----------|
| 急停按钮 | 未按下（NC 闭合） | ✅ |
| 急停按钮 | 按下（NC 断开） | ❌ |
| 安全门 | 关闭（门磁闭合） | ✅ |
| 安全门 | 打开（门磁断开） | ❌ |
| 左限位 | 未触发 | ✅ |
| 左限位 | 触发（NC 断开） | ❌ |
| 右限位 | 未触发 | ✅ |
| 右限位 | 触发（NC 断开） | ❌ |
| 启动按钮 | 按下（NO 闭合） | ✅（仅脉冲） |
| 气压正常 | 传感器 ON | ✅ |
| 气压不足 | 传感器 OFF | ❌ |

**启动允许 = 急停未按 AND 安全门关闭 AND 左限位未触发 AND 右限位未触发 AND 气压正常 AND 启动按钮按下**

## 现场感悟

- **常闭比常开安全**：急停、限位用常闭，断线时自动触发保护，不会"失效了还不知道"
- **消抖**：机械按钮按下时有 10-20ms 抖动，PLC 程序或 Arduino 必须加延时消抖，否则一次按下触发多次
- **PNP/NPN 混用**：现场换传感器时没注意 PNP/NPN，直接烧 PLC 输入点，教训深刻

## 与 Arduino 试验台的关联

Arduino 数字输入 `digitalRead()` 读到的就是开关量。必须逐条建立"硬件状态 → 代码变量 → 程序行为"的映射，不能跳过。待办 4 号试验台的核心就是把这个真值表跑通。
