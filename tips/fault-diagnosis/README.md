# 日志解析实战：从柏楚日志发现周期性参数漂移

## 背景

柏楚控制系统日志量极大，人工翻查效率低。通过 Python 脚本自动化提取关键事件，发现隐藏规律。

## 发现的问题

某设备每周一早晨 8:00-9:00 高频报警（报警代码 E-203），周二至周五正常。

## 排查过程

1. **日志扫描**：提取过去 3 个月所有 E-203 报警的时间戳
2. **时间分布统计**：按星期几分组，发现周一占比 78%
3. **关联分析**：对比周一与其他日的开机参数，发现周末关机后冷启动，气压预热时间不足，导致首小时切割气压不稳定

## 根因

周末关机 → 周一冷启动 → 气压系统预热时间被跳过（操作工为赶进度提前起刀）→ 气压不足触发 E-203

## 解决

- 在 NCEX 参数中增加冷启动预热延时 30 秒
- 用脚本监控周一早晨前 10 个工件的报警率，异常时自动提醒班组长
