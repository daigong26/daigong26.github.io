# 宿主虚拟工控联调

## 场景

在没有实体 PLC 或激光切割控制器的情况下，通过虚拟环境完成程序逻辑验证，减少现场调试时间。

## 环境搭建

- 虚拟机：VMware / VirtualBox
- PLC 模拟软件：根据品牌选择（如西门子 PLCSIM、三菱 GX Simulator）
- 通信中间件：Modbus TCP 模拟器

## 联调步骤

1. **虚拟 PLC 配置**：在虚拟机中安装 PLC 编程软件，编写基础逻辑
2. **通信测试**：用 Modbus Poll/Scan 工具验证寄存器读写
3. **上位机对接**：Python 脚本通过 Modbus TCP 连接虚拟 PLC，测试数据采集
4. **逻辑验证**：模拟传感器信号（开关量）、电机反馈（模拟量），验证程序分支
5. **现场迁移**：逻辑确认后，下载到实体 PLC，只需微调 IO 映射

## 踩坑记录

- 虚拟机与宿主机防火墙可能阻断 Modbus 端口（默认 502），需提前放行
- 虚拟 PLC 的时钟与宿主机不同步，导致定时器类逻辑测试偏差
- 部分模拟器不支持中断功能，复杂逻辑仍需上实体机验证

## 价值

- 现场调试时间减少 40%
- 避免直接在实体设备上试逻辑导致的误动作风险
