# DXF 图纸拆分器

## 解决什么现场问题

套料前处理阶段，总装 DXF 图纸拆分为单零件图并标注十字标，手工操作 100 零件耗时 40 分钟，漏标率 5%。

## 功能

- 自动识别 DXF 中的多零件轮廓
- 按零件名称拆分输出独立 DXF 文件
- 在每个零件中心自动标注十字标（对中标记）
- 生成拆分清单（CSV），含零件名、尺寸、数量

## 技术点

- Python `ezdxf` 库解析 DXF 格式
- 几何轮廓识别与边界框计算
- 坐标变换与标注自动插入

## 使用示例

```bash
python dxf_splitter.py --input 总装图.dxf --output-dir ./parts/
```

## 效果

- 拆分 100 个零件的图纸，人工 40 分钟 → 脚本 2 分钟
- 十字标漏标率从 5% 降到 0
