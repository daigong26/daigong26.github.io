# 激光切割数据库管理系统

## 解决什么现场问题

工艺参数长期分散在几十个 Excel 文件，版本混乱，查询慢，批量修改易错，跨班次交接易遗漏。

## 方案

用 Python + SQLite 搭建轻量级工艺参数数据库，实现统一存储、快速查询、批量下发。

## 技术点

- Python 3.x
- SQLite 轻量数据库
- 正则解析 NCEX 工艺文件格式
- 批量文件读写与备份

## 使用示例

```bash
python laser_db.py --query --material 碳钢 --thickness 5
python laser_db.py --export --machine HSG-LS20A
```

## 效果

- 参数查询时间从 5 分钟（翻 Excel）降到 10 秒
- 批量修改 50 个工艺文件，人工 2 小时 → 脚本 3 分钟
